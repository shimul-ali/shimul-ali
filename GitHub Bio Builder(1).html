  1. বামের ঘরগুলো পূরণ করো। ইংরেজিতে লেখো, কারণ recruiter-রা ইংরেজিতেই দেখবে। সব ঘর না ভরলেও চলবে, শুধু Role দরকার।
  2. ডানে ৪টা bio দেখবে। যেটা সবচেয়ে ভালো লাগে তার Copy বাটনে চাপো। সংখ্যাটা ১৬০ এর নিচে থাকলে ঠিক আছে।
  3. GitHub-এ bio বসাও: github.com খুলে ওপরের ডান কোণে তোমার ছবিতে চাপো, তারপর Settings, তারপর Public profile। Bio ঘরে Paste করো (Ctrl+V), তারপর নিচে Update profile চাপো।
  4. README বানাও (পরে করলেও চলবে): নিচের ধাপগুলো README অংশে দেওয়া আছে।

Profile README starter

  1. উপরের Copy README চাপো।
  2. GitHub-এ ওপরের + চিহ্নে চাপো, তারপর New repository।
  3. Repository name-এ ঠিক তোমার username লেখো (বানান হুবহু মিলতে হবে)। Public রাখো এবং Add a README file টিক দাও, তারপর Create repository।
  4. README.md খুলে পেন্সিল (Edit) আইকনে চাপো, সব মুছে Paste করো, আর Commit changes চাপো।
  5. "add link", "add address" আর "Project name" লেখাগুলো নিজের তথ্য দিয়ে বদলে নাও।

Fresher দের জন্য checklist

  • ছবি: Settings → Public profile থেকে নিজের পরিষ্কার মুখের ছবি দাও।
  • Name: Public profile-এ তোমার আসল নাম লেখো।
  • Pin: profile পেজে Customize your pins চেপে সেরা ৪ থেকে ৬টা project বেছে নাও।
  • Description: প্রতিটা repository-র ডানে gear আইকনে চেপে এক লাইনে লেখো project টা কী করে।
  • নিয়মিত কাজ: সপ্তাহে কয়েকদিন ছোট ছোট commit করো, ছোট করে পরিষ্কার লেখো কী বদলালো।
  • Username: চাইলে Settings → Account থেকে username আসল নামের মতো করো। বদলালে পুরনো profile লিংক আর কাজ করবে না, তাই আগে ভেবে নাও।
